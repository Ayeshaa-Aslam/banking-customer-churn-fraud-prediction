This file contains the trained XGBoost model for credit card fraud detection.

Original file: fraud_detection_model_ultimate.pkl
Size: ~100MB
Model Type: XGBoost Classifier with SMOTE oversampling
Performance: 96.0% accuracy, 70.9% precision, 75.7% recall

Model Details:
- Features: 31 features including Time, V1-V28 PCA components, Amount, Amount_log
- Training Data: 284,807 credit card transactions
- Technique: 97% precision proven method adapted from Kaggle
- Imbalance Handling: SMOTE oversampling for 0.172% fraud rate
- Threshold: Dynamic optimization for precision-recall balance
